# FinTrack

FinTrack adalah aplikasi sederhana untuk mencatat pemasukan dan pengeluaran menggunakan Python.

Project ini saya buat untuk belajar membuat aplikasi dari dasar, mulai dari input data, penyimpanan data, pengolahan transaksi, sampai penggunaan Git dan GitHub.

# Fitur

- Tambah pemasukan
- Tambah pengeluaran
- Melihat semua transaksi
- Melihat saldo
- Menghapus transaksi
- Melihat laporan pengeluaran berdasarkan kategori
- Filter transaksi berdasarkan jenis
- Filter transaksi berdasarkan kategori
- Validasi nominal dan tanggal
- Data disimpan dalam file JSON

# Teknologi

- Python
- JSON
- Git
- GitHub

# Cara Menjalankan

Pastikan Python sudah terinstall di komputer.

1. Clone repository
git clone https://github.com/ZikriYahya/fintrack.git
2. Masuk ke folder project
cd fintrack
3. Jalankan program
python main.py
